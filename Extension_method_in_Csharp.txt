# Extension Methods in C#

In .NET Core / modern .NET, an extension method lets you add a new method to an existing type without modifying the original type or creating a derived class.

This is especially useful when you want to add reusable functionality to types you do not own, such as string, int, List<T>, DateTime, and so on.

## What is an Extension Method?

An extension method is a static method defined in a static class. It is called as if it were an instance method of the extended type.

The key idea is the `this` keyword in the first parameter.

## Syntax

```csharp
public static class StringExtensions
{
    public static string ToCapitalized(this string text)
    {
        if (string.IsNullOrEmpty(text))
            return text;

        return char.ToUpper(text[0]) + text.Substring(1).ToLower();
    }
}
```

Important part:

```csharp
this string text
```

This tells C# that `ToCapitalized()` is an extension method for `string`.

## Example

```csharp
string name = "john";
string result = name.ToCapitalized();

Console.WriteLine(result);
```

Output:

```text
John
```

## Why Use Extension Methods?

Extension methods are useful when:

- You want to add logic to a type you do not own
- You need reusable helper methods for common operations
- You want cleaner and more readable code
- You want to extend built-in types like `string`, `DateTime`, or `List<T>`

For example, LINQ methods like `Where()`, `Select()`, and `OrderBy()` are extension methods.

```csharp
List<int> numbers = new List<int> { 1, 2, 3, 4, 5 };

var evenNumbers = numbers.Where(x => x % 2 == 0);
```

`Where()` is not a method of `List<T>` itself. It is added by LINQ as an extension method.

## Rules for Extension Methods

An extension method must follow these rules:

- It must be inside a static class
- It must itself be static
- Its first parameter must use the `this` keyword
- The type being extended is specified in the first parameter

## Example with Real-World Usage

```csharp
public static class StringExtensions
{
    public static bool IsValidEmail(this string email)
    {
        if (string.IsNullOrWhiteSpace(email))
            return false;

        return email.Contains("@") && email.Contains(".");
    }
}
```

Usage:

```csharp
string email = "user@example.com";

if (email.IsValidEmail())
{
    Console.WriteLine("Valid email");
}
else
{
    Console.WriteLine("Invalid email");
}
```

## Best Practices

Use extension methods only when they truly improve readability and usability.

### Good practices

- Keep them simple and focused
- Use clear and meaningful names
- Put related methods in the same static class
- Use namespaces to avoid conflicts
- Favor extension methods for cross-cutting reusable logic

### Avoid

- Creating extension methods that duplicate built-in methods
- Adding very general logic that belongs in a normal utility class
- Naming methods confusingly or too broadly
- Overusing extension methods on common types just for convenience

## Benefits of Extension Methods

- Code becomes cleaner and easier to read
- You avoid changing third-party or framework code
- You can add reusable functionality across many classes
- They are very useful in LINQ and utility libraries

## Limitations

- Extension methods do not truly modify the original type
- They are static methods behind the scenes
- They cannot override existing instance methods
- If there is an existing method with the same name, the original method takes precedence

## Interview Questions and Answers

### Q1: What is an extension method in C#?

An extension method is a static method that allows you to add new functionality to an existing type without modifying the type itself.

### Q2: What keyword is required in the first parameter of an extension method?

The `this` keyword is required.

### Q3: Can extension methods be defined in a non-static class?

No. They must be defined in a static class.

### Q4: Can extension methods override an existing instance method?

No. Extension methods do not override existing methods. The original method is used first.

### Q5: Why are extension methods useful?

They are useful for adding reusable functionality to types that you cannot modify, and they are commonly used in LINQ.

### Q6: Is there any performance cost of using extension methods?

No major performance cost exists. They are compiled as regular static method calls, so they are efficient and simple to use.

## Summary

An extension method:

- Must be inside a static class
- Must itself be static
- Must use the `this` keyword in the first parameter
- Lets you add behavior to an existing type without modifying it

This feature is widely used in .NET and is one of the most important concepts in modern C# development.

## Final Thoughts

Extension methods are a powerful feature in C#. They help developers write cleaner, reusable, and maintainable code. They are especially useful when working with libraries and built-in types where modifying the original source is not possible.

If you understand extension methods correctly, you can write better code and also answer many C# interview questions confidently.
