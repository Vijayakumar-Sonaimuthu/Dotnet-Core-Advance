# Extension Methods in C#

Extension methods are one of the most useful features in C#. They allow you to add new methods to an existing type without modifying the original class or creating a derived class.

This is especially powerful when working with built-in types like `string`, `int`, `DateTime`, or `List<T>`, as well as third-party libraries where you cannot change the source code.

---

## What is an Extension Method?

An extension method is a static method defined inside a static class. It is called as if it were an instance method of the type it extends.

The key part is the `this` keyword in the first parameter.

```csharp
public static class StringExtensions
{
    public static string ToCapitalized(this string text)
    {
        if (string.IsNullOrEmpty(text))
            return text;

        return char.ToUpper(text[0]) + text.Substring(1).ToLower();
    }
}
```

Here:

```csharp
this string text
```

means: “This method extends the `string` type.”

---

## Simple Example

```csharp
string name = "john";

string result = name.ToCapitalized();

Console.WriteLine(result);
```

Output:

```text
John
```

This makes the code cleaner, easier to read, and more reusable.

---

## Why Use Extension Methods?

Extension methods are useful when:

- You want to add new behavior to a type you do not own
- You want reusable helper methods for common logic
- You need cleaner and more readable code
- You want to extend built-in or third-party types without changing their source

A common example is LINQ.

```csharp
List<int> numbers = new List<int> { 1, 2, 3, 4, 5 };

var evenNumbers = numbers.Where(x => x % 2 == 0);
```

`Where()` is an extension method provided by LINQ. You did not modify `List<T>` itself; LINQ extended it.

---

## Rules for Extension Methods

An extension method must follow these rules:

- It must be declared inside a `static` class
- It must itself be `static`
- Its first parameter must use the `this` keyword
- The type being extended is specified in that first parameter

Example:

```csharp
public static class MathExtensions
{
    public static int Square(this int number)
    {
        return number * number;
    }
}
```

Now you can use it like this:

```csharp
int x = 5;
int result = x.Square();

Console.WriteLine(result); // 25
```

## Real-World Example

Suppose you want to validate email addresses using an extension method.

```csharp
public static class StringExtensions
{
    public static bool IsValidEmail(this string email)
    {
        if (string.IsNullOrWhiteSpace(email))
            return false;

        return email.Contains("@") && email.Contains(".");
    }
}
```

Usage:

```csharp
string email = "user@example.com";

if (email.IsValidEmail())
{
    Console.WriteLine("Valid email");
}
else
{
    Console.WriteLine("Invalid email");
}
```

This keeps your business logic readable and reusable.

## Best Practices

Use extension methods carefully. They are powerful, but overusing them can make code confusing.

### Good practices

- Use them for reusable logic
- Keep methods focused and simple
- Use clear and meaningful names
- Put related extension methods in one static class
- Keep namespaces organized to avoid conflicts

### Avoid

- Creating extension methods that duplicate existing built-in methods
- Adding too many methods to basic types
- Writing overly broad methods that should be regular utility functions
- Naming methods confusingly or too generically

---

## Advantages of Extension Methods

- You can add methods to a type without modifying its source
- Code becomes cleaner and easier to read
- They are useful for reusable logic across many classes
- They are widely used in LINQ and .NET libraries

---

## Limitations

Although extension methods are very useful, they have some limitations:

- They do not actually modify the original type
- They cannot override existing instance methods
- If a type already has a method with the same name, that method is used first
- Overuse can reduce code clarity if used carelessly

## Interview Questions and Answers

### Q1: What is an extension method in C#?

An extension method is a static method that allows you to add new functionality to an existing type without modifying that type.

### Q2: What keyword is required in the first parameter?

The `this` keyword is required.

### Q3: Can extension methods be defined in a non-static class?

No. Extension methods must be inside a static class.

### Q4: Can extension methods override existing methods?

No. Extension methods do not override existing methods. The original method takes priority.

### Q5: Why are extension methods useful?

They help you extend types you cannot change directly and keep code reusable and readable.

### Q6: Are there any performance issues with extension methods?

No major performance cost exists. They are compiled as static method calls and work efficiently.
